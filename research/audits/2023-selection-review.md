# 2023 年事件选材复核

核查日期：2026-09-14；2026-09-15追加主次与素材校正。对象起初为24个年度节点与1条前情，首轮新增7项；后续又补入美国第14110号行政命令。层级与重要性判断属于编辑判断，不是来源给出的客观排名。

## 结论

原清单抓住了 ChatGPT 破圈、GPT-4、厂商竞逐、Llama 2、国内开放与监管等显著节点，但整体偏向公告：24 条中，16 条是模型、产品或功能公告，另有 2 条 OpenAI 人事变动。它能回答“谁在什么时候发布了什么”，尚不足以解释参与门槛、产业资源和人的工作怎样变化。

最缺的不是更多产品名称，而是三条脉络：**开放模型如何变得跑得起、改得动；AI 热潮如何转成算力需求；创作者如何争取具体工作规则。** 前五项技术补项提供可追溯的早期节点，后两项补产业与人的影响。不要把全部新增项抬到主视图，年度层只露出主要转折，技术项目收进可展开分支。

“早期伏笔”应表示后来已有具体延续或采用证据；本轮不能证明这些项目当时“无人关注”，也不统一宣称它们各自“改变了整个行业”。

## 原有 24 条的层级建议

三类是选材理由，可以重叠；表中列首要理由。主脉络表示年度总览入口，分支表示年度展开后可见，细节表示进入相关事件后才展开。

| 原节点 | 首要理由 | 建议位置与处理 |
|---|---|---|
| 纽约学校限制访问 | 广泛影响／社会反应 | 教育使用分支的具体案例；不以一地政策概括所有学校 |
| ChatGPT 用户增长 | 重大转折 | “ChatGPT 破圈”主脉络，保留机构估算口径 |
| ChatGPT Plus | 广泛影响／商业化 | ChatGPT 商业化细节，不必独占年度主节点 |
| Bard 公布 | 重大竞逐 | 与新 Bing 同置搜索竞逐分支，分别保留日期和开放边界 |
| 新 Bing | 重大转折 | 搜索与应用入口的代表节点，有限预览区别于普及 |
| LLaMA | 早期伏笔／开放生态 | 开放模型主脉络的起点，连向 Llama 2、社区微调、本地运行；不可称当时可自由商用 |
| GPT-4 | 重大转折 | 能力演进主脉络 |
| Claude 首次公布 | 后续重要参与者 | 厂商竞逐分支，不能仅凭今天的地位抬高首发当天影响 |
| 文心一言发布 | 广泛影响／国内竞逐 | 国内模型竞逐分支，与公众开放分别记载 |
| Microsoft 365 Copilot | 重大转折／应用入口 | “AI 进入工作软件”主脉络的代表；发布演示不等于实际全面落地 |
| 暂停训练公开信 | 广泛影响／公共争论 | 治理讨论分支，与立法、实施严格分开 |
| 通义千问公布 | 广泛影响／国内竞逐 | 国内竞逐分支，后续开放权重应另有事实节点 |
| PaLM 2 | 产品迭代 | Google 路径下的细节；年度主屏不与 GPT-4 等权 |
| AI 孙燕姿 | 广泛影响／大众创作 | “生成内容进入大众文化”主脉络的代表，保留传播材料，勿只剩版权结论 |
| 中国生成式 AI 暂行办法 | 重大转折／规则 | 治理主脉络，公布与施行是两个时间点 |
| Llama 2 | 重大转折／开放生态 | 开放模型主脉络的关键节点，许可证限制进入详情 |
| 文心一言公众开放 | 广泛影响／实际可用 | 国内使用入口的关键分支；未来补同批其他产品后再概括整体开放 |
| ChatGPT 语音和图像 | 能力与使用扩展 | 多模态分支，与此前“宣布支持”及随后 rollout 区分 |
| DALL·E 3 进入 ChatGPT | 产品接入 | 图像创作／多模态分支的细节 |
| OpenAI DevDay | 开发方式变化 | 开发者工具分支，应补具体采用证据再判断持续影响 |
| Altman 离任 | 广泛影响／公司治理 | 与回归合成一个治理事件入口，内部仍保留各时间点 |
| Altman 回归正式公告 | 同上 | 前一事件的后续细节，不另占年度总览节点 |
| Gemini 公布 | 厂商与多模态竞逐 | Google／多模态分支，型号与开放安排进入详情 |
| 欧盟 AI 法案临时协议 | 重大转折／规则 | 治理主脉络，2023 年达成协议与后续正式通过分开 |

2022-11-30 的 ChatGPT 前情应留在跨年时间轴；2023 的公众爆发不可被提前写成 2022 当天已经完成。

## 首轮新增的 7 个优先节点

### 1. llama.cpp：本地运行的一条早期路径

- **原始日期：2023-03-10。** 仓库首个无父提交名为 `Initial release`；原提交页面内嵌元数据显示 authoredDate 为 `2023-03-10T20:40:58+02:00`、committedDate 为 `2023-03-10T20:56:40+02:00`。应标“首个代码提交”，不额外推断精确公开曝光时间。[首个提交](https://github.com/ggml-org/llama.cpp/commit/26c084662903ddaca19bef982831bfb0856e8257)
- **当时性质：** C/C++ 模型推理项目，是开发者可继续改造的软件起点；首发范围不能套用今天的多硬件能力。
- **后续证据：2023-11-29。** Mozilla 发布 llamafile，明确说明它依赖 llama.cpp 与 Cosmopolitan，将模型打包为跨平台可执行文件。[Mozilla 公告](https://hacks.mozilla.org/2023/11/introducing-llamafile/)
- **后续证据：2024-10-22。** LM Studio 0.3.5 已将 llama.cpp 与 Apple MLX 作为本地服务能力的底层引擎选项。[LM Studio 发布说明](https://lmstudio.ai/blog/lmstudio-v0.3.5)
- **判断：纳入早期伏笔分支。** 已有不同下游软件采用证据，适合从 LLaMA 展开至“模型在自己机器上运行”；足以证明技术延续，不能据此证明首发时无人注意或市场占有率。

### 2. Chatbot Arena：让用户参与比较模型

- **原始日期：2023-05-03，初始榜单文章。** 文章介绍匿名随机双模型对战与用户投票，首批榜单依据 04-24—05-01 的约 4,700 票；因此 05-03 是文章／初榜日期，不应写成平台第一次接受投票的日期。迁移后站点显示 05-04，本项目采用原 LMSYS 署日并保留差异。[原文](https://www.lmsys.org/blog/2023-05-03-arena/)
- **当时性质：** 研究团队的开放评测实验，试图补足只看固定题库的比较方式。
- **后续证据：2023-12-07。** 团队公布累计超过 13 万有效投票、覆盖超过 40 个模型，并将评分从在线 Elo 调整为 Bradley–Terry 模型。[年末更新](https://www.lmsys.org/blog/2023-12-07-leaderboard/)
- **判断：纳入早期伏笔／评测分支。** 同年已有持续增长与方法迭代证据，能说明“谁来判断模型好不好”这一重要变化。榜单测的是其样本内的人类偏好，不是所有任务的统一能力排名；目前这些规模数据来自运营方。

### 3. QLoRA：降低微调的显存门槛

- **原始日期：2023-05-23，论文首次提交。** 研究提出在量化基座模型上训练低秩适配器的方法，报告在单张 48GB GPU 上微调 65B 模型；这是论文配置及结果，不等于任意模型都能以同样成本运行。[论文](https://arxiv.org/abs/2305.14314)
- **当时性质：** 训练效率方法，主要面向研究者和模型开发者。
- **后续证据：2024-04-18。** Hugging Face 为 Llama 3 提供的官方集成文章直接将 4-bit QLoRA 与 TRL 用作微调示例。[Llama 3 集成](https://huggingface.co/blog/llama3)
- **判断：纳入早期伏笔分支。** 从论文到新一代模型的实际工具链集成可追溯；与本地推理分开，避免把“能跑模型”误写成“能训练模型”。无需把论文的有条件性能对比变成笼统的“媲美 ChatGPT”。

### 4. DPO：另一种偏好对齐方法

- **原始日期：2023-05-29，论文首次提交。** DPO 提出直接使用偏好数据优化模型的方法，减少传统 RLHF 流程中单独训练奖励模型等步骤。[论文](https://arxiv.org/abs/2305.18290)
- **当时性质：** 训练方法研究，公众未必会直接接触这个名称。
- **后续证据：2024-07-23。** Meta 的 Llama 3.1 官方说明明确把 DPO 列入其多轮后训练流程，和监督微调、拒绝采样共同使用。[Meta Llama 3.1](https://ai.meta.com/blog/meta-llama-3-1/)
- **判断：纳入早期伏笔的技术细节。** 有大型模型实际采用的明确证据，比只引用论文数量更具体。它是后训练方法之一，不能写成取代全部 RLHF，或把 Llama 3.1 的全部进步归因于 DPO。

### 5. vLLM：让模型服务承载更多请求

- **原始日期：2023-06-20，项目介绍公告。** 团队介绍 vLLM 与 PagedAttention，用于模型推理和服务；公告称此前两个月已用于 Chatbot Arena 与 Vicuna Demo，因此本节点应称“公开介绍”，不称首次实际运行。[项目公告](https://vllm-project.github.io/2023/06/20/vllm.html)
- **当时性质：** 服务端基础设施项目，解决显存管理与并发吞吐问题，不是另一款聊天机器人。
- **后续证据：2024-04-08。** AWS 的 SageMaker 容器介绍明确列出 LMI vLLM 后端及其支持能力。[AWS 采用说明](https://aws.amazon.com/blogs/machine-learning/boost-inference-performance-for-mixtral-and-llama-2-models-with-new-amazon-sagemaker-containers/)
- **判断：纳入早期伏笔／基础设施分支。** 从研究团队服务到云平台集成有直接证据；“最多 24 倍吞吐”等首发性能数字仅适合有条件的技术详情，主节点不必使用。

### 6. NVIDIA 财报：算力需求开始体现在经营数字上

- **原始日期：2023-05-24，FY2024 第一季度财报公告。** NVIDIA 披露当季数据中心收入 42.8 亿美元，预计下一季度总收入 110 亿美元，并表示正在增供以应对需求。[首季公告](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-first-quarter-fiscal-2024)
- **当时性质：** 已广受关注的产业经营信号，不能包装成“无人注意的小事”。FY2024 是财年名称，事件发生在自然年 2023。
- **后续证据：2023-08-23。** 次季公告披露数据中心收入 103.2 亿美元，环比增长 141%，实际收入变化提供了后续验证。[次季公告](https://nvidianews.nvidia.com/news/nvidia-announces-financial-results-for-second-quarter-fiscal-2024)
- **判断：纳入产业／算力主脉络。** 补足此前只有模型发布、没有生产资源变化的问题。不要将数据中心收入全部归因为生成式 AI，也不以单日股价替代实际经营变化。

### 7. WGA 合同中的 AI 条款：工作规则开始具体化

- **原始日期：2023-09-25，协议文本日期及约定生效起点。** WGA 的 2023 协议新增生成式 AI 条款，明确 AI 不具有协议内的编剧身份等规定；当时条款仍有成员批准条件。[协议原文，PDF 第 1 页及第 68—70 页](https://www.wga.org/uploadedfiles/contracts/2023_MBA_MOA.pdf)
- **当时性质：** 集体劳动谈判的具体结果，不是模型发布，也不是泛化的“人类被取代”讨论。[工会条款摘要](https://www.wgacontract2023.org/the-campaign/summary-of-the-2023-wga-mba)
- **后续证据：2023-10-09。** WGA 宣布成员批准协议，99% 有效票赞成；公告同时确认协议期从 09-25 起算。[批准公告](https://www.wgacontract2023.org/announcements/2023-mba-ratified)
- **判断：纳入“创作、工作与规则”分支的重要节点。** AI 使用从抽象忧虑进入劳动条款，是文化与社会影响的具体证据；不把整个罢工归因于 AI，不将覆盖特定协议的规定扩写成全球法律，也不据此宣称职业风险已解决。

## 2026-09-15 主次与素材校正

美国第14110号行政命令补为治理主节点：2023-10-30签署、11-01刊登，后续于2025-01-23被第14179号行政命令撤销。它与中国管理办法、欧盟临时协议并列呈现不同制度路径；行政命令、行政部门任务与国会立法严格区分。OpenAI管理层危机降为分支，仍保留离任与回归两个时间点。

本轮没有继续增加模型名单，而是为新Bing、GPT-4、AI翻唱、NVIDIA财报和WGA协议补入具体材料；连同2022的Copilot订阅与Stable Diffusion下载运行场景，早期年份不再只剩发布日期。2023现有32事件、9主节点、23分支和8则时代材料。

## 暂不写成“已证明巨大影响”的候选

- **AutoGPT：** 值得补为 2023 年代理热潮的代表，但本轮未完成初次发布日期的一手核定，拟用的 Jina 历史体验原文已返回 404，也未找到足以把后续代理产业直接归因于它的采用链。先留候选，不制造“当时冷门、后来改变世界”的确定故事。
- **Mistral／Mixtral、Qwen 开放权重、图像与视频生成：** 是下一轮覆盖复核优先项；当前 7 项补充仍不足以宣称 2023 年已经全面。尤其不能因补了开发者技术，进一步挤掉创作者、普通用户与国内生态。
- **AI 科研、机器人与游戏赛事：** 本清单仍偏生成式 AI。若年度地图使用“AI 全史”而不是“这一轮 AI 浪潮”，这些领域需要独立补查。赛事按真实年度影响进入支线，不能为了沿用最初题材而预设主线位置。

## 年度关键词与更新方式

**2023｜破圈与竞逐**

**关键句：AI 从一个聊天窗口走进公众生活，也点燃了行业竞逐。**

这是对现有材料的编辑概括，能同时容纳使用热潮、厂商竞逐和开放生态，不表示所有社会领域都已经普遍应用 AI。后续若增加技术层的年度副句，可用“模型变强，入口变多，参与门槛开始下降”，避免让一个关键词承担全部解释。

每个早期节点在数据上应分开保存 `occurred_at`、当时性质与资料、后续影响证据日期、影响判断及其更新日期。关系边只使用有证据的“采用”“基于”“后续版本”；同期发生或共同主题不能自动连成因果。主层级、重要性类型、当时热度、后续影响分别维护，更新时才不会把今天的认识伪装成当年的共识。
